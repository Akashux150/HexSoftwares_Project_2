 Python Voice Assistant

This project is a Python-based Voice Assistant developed as part of my internship at HexSoftwares.

The assistant can recognize voice commands and perform various tasks such as telling the time, searching Wikipedia, playing YouTube videos, and opening applications.

---
 Features

✔ Voice Recognition using SpeechRecognition  
✔ Text-to-Speech response using pyttsx3  
✔ Wikipedia search  
✔ Play YouTube videos  
✔ Open Google & YouTube  
✔ Open Notepad  
✔ Exit command  
✔ Dynamic greeting based on time  

---

Technologies Used

- Python 3.10
- SpeechRecognition
- PyAudio
- pyttsx3
- Wikipedia
- pywhatkit
- Webbrowser module
- OS module

Installation & Setup

 Step 1: Install Python 3.10
Download and install Python 3.10 (64-bit)

Step 2: Install Required Libraries

Run the following commands:

py -3.10 -m pip install pyaudio  
py -3.10 -m pip install SpeechRecognition  
py -3.10 -m pip install pyttsx3  
py -3.10 -m pip install wikipedia  
py -3.10 -m pip install pywhatkit  

---

## ▶ How to Run

In terminal, run:

py -3.10 assistant.py
